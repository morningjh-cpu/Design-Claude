먼저 할 일

  1. 글자 스타일 연결 — 스타일 18개를 Wanted Sans로 바꾼 뒤 부품 글자에 연결 (가장 큰 빈칸). 다른 서체 800곳은 Wanted Sans로
  2. 상태 이름 한 벌로 맞추기 — name 칸 정리, 철자 고치기, selected/active 통일. 피그마 안의 이름이라 화면 연결은 유지됨 (개발 쪽 이름과 맞춰야 하는지 확인 필요)
  3. 빠진 상태 채우기 — checkbox·radio·switch·탭 올림, 버튼류·태그·페이지 버튼 비활성. 저장값에 이미 hover·disabled 색이 있는 경우가 많음 (안 쓰는 저장값 목록 참고)
  4. 검정·흰색 용도 정하기 — 화면 직접 색 대부분. 부품별로 tx-primary / tx-inverse / bg-primary 등 정하면 다크 모드도 맞게 바뀜
  5. 부품 설명 달기 — 버튼·입력부터 /design-system document 로
