# 14 find-skills — 필요한 스킬 찾아 주기

**쓰는 일:** 기획 ● 디자인 ● 개발 ● (분야 무관)

부르는 법: "~하는 스킬 있어?", "~ 도와줄 스킬 찾아줘" 라고 말하면 자동 · 직접 `/find-skills (찾는 것)`

## 상황별
| 상황 | 이렇게 말하기 |
|---|---|
| 이런 일을 도와줄 스킬이 있는지 궁금할 때 | "피그마 접근성 점검 스킬 있어?" |
| 분야별 인기 스킬 보기 | "테스트 자동화 쪽 인기 스킬 찾아줘" |
| 찾은 스킬 설치 | "그거 설치해줘" (설치 후 이 목록·설명서도 갱신) |

## 어떻게 찾나
- skills.sh 순위(설치 수 많은 순) → `npx skills find (검색어)` 로 검색
- 추천 기준: 설치 수 1천 이상, 믿을 만한 곳(vercel-labs·anthropics·microsoft 등), 깃허브 별 100 이상

## 주의
- 보안 평가: Gen "안전", Socket "경고 0", Snyk "중간 위험". 스킬이 "확인 없이 바로 설치(-y)"하라고 안내하는 부분 때문으로 보임(추측) → **설치는 항상 사용자 확인 후** 하고, 설치 전에 내용·바깥 전송을 살펴봄
- 검색은 인터넷(skills.sh·깃허브)에 검색어를 보냄 → 회사 내부 정보는 검색어에 넣지 않기
- `npx skills`로 설치한 스킬은 `~/.claude/skills/`에 들어감 (플러그인 목록 `claude plugin list`에는 안 나옴)
