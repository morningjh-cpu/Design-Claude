# 03 taste-skill — 웹페이지 디자인 방향 뽑기

**쓰는 일:** 디자인 ●  기획 ●(페이지 구성·문구)  개발 ●(웹 화면 코드)

부르는 법: `/taste-skill (요청)` 또는 "테이스트 스킬로 ~"

## 상황별
| 상황 | 이렇게 말하기 |
|---|---|
| 소개·랜딩 페이지를 새로 만들 때 | `/taste-skill 와이즈리포트 서비스 소개 페이지` |
| 페이지가 "AI가 만든 것 같다", 흔해 보일 때 | `/taste-skill 이 페이지가 템플릿 같아, 다시 잡아줘` |
| 대시보드·설정 같은 작업 화면 | `/taste-skill 리포트 목록 대시보드` (앱 화면 방식으로 자동 전환) |
| 기존 브랜드 색·글꼴은 지키고 배치만 새로 | "브랜드 색·글꼴 유지하고 방향만 뽑아줘" |

## 일하는 순서
1. 자료 확인(실제 사진·화면이 있는지) → 2. 이 서비스만의 것 8~12개 적기 → 3. 방향 3개를 뽑아 하나 고르기 → 4. 아이디어 한 줄 → 5. 문구 먼저 → 6. 만들고 화면 폭 3가지로 캡처해 고치기

## 이 프로젝트에서 써 본 예
- 1차 B안, 2차 B2, 3차 ②안("조용한 도구" 방향)

## 주의
- 결과물이 웹 코드. 피그마에서는 방향 뽑기만 활용
- Node 22 이상·크롬 필요, 프로젝트에 `.taste-skill/` 작업 폴더가 생김
- 사진 찾기 기능은 공개 자료실(위키미디어 등)에 접속 — 키 불필요
- 아무 자료 없이 쓰면 과감해지기 쉬움(1차 B안 "과도함" 평) → "과하지 않게"를 같이 말하기
