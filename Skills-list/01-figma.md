# 01 figma — 피그마 읽기·만들기·고치기

**쓰는 일:** 디자인 ●  개발 ●  기획 ○(다이어그램·기획 보드)

부르는 법: 따로 명령 없이 "피그마에서 ~해줘" + 피그마 주소(링크)를 주면 자동으로 맞는 기능을 씀.

## 상황별 말하는 법
| 하고 싶은 일 | 이렇게 말하기 | 속에서 쓰는 기능 |
|---|---|---|
| 피그마 화면을 고치기·새로 그리기 | "이 프레임 오른쪽에 개선안 만들어줘 (링크)" | figma-use + figma-generate-design |
| 피그마 화면을 웹 코드로 옮기기 | "이 피그마 화면을 코드로 만들어줘 (링크)" | figma-design-to-code |
| 웹페이지(코드)를 피그마로 가져오기 | "이 페이지를 피그마로 옮겨줘" | figma-generate-design |
| 색·글자·버튼 등 디자인시스템 만들기 | "이 프로젝트 색·버튼을 피그마 라이브러리로 만들어줘" | figma-generate-library |
| 피그마 부품과 코드 부품 연결 | "버튼 부품을 코드와 연결해줘" (Code Connect: 피그마 부품 ↔ 코드 짝 맺기) | figma-code-connect |
| 흐름도·구조도 그리기 | "회원가입 흐름도를 피그잼에 그려줘" | figma-generate-diagram |
| 새 피그마 파일 만들기 | "새 피그마 파일 만들어줘" | figma-create-new-file |
| 피그마 움직임을 코드로 | "이 애니메이션을 코드로 구현해줘" | figma-implement-motion |
| 피그마 안에서 움직임 넣기 | "이 버튼에 눌림 애니메이션 넣어줘" | figma-use-motion |
| 기획서(PRD) 쓰기·읽기 | "피그마 기획 문서 정리해줘" | figma-spec |
| 피그잼·슬라이드 작업 | "피그잼 보드에 회의 내용 정리" | figma-use-figjam / figma-use-slides |

## 이 프로젝트에서 써 본 예
- 서비스 소개 개선안 1~3차, Hallmark 리디자인(12577:3650) — 기준 화면을 복제해서 고치는 방식

## 주의
- Wanted Sans 글꼴은 피그마 작업 도구가 못 불러옴 → 글자 내용·정렬은 손으로. 복제한 글자의 크기(비율)·색은 바꿀 수 있음
- 피그마 데스크톱 앱이 켜져 있어야 함
- 결과는 화면 캡처로 확인하고 받기
