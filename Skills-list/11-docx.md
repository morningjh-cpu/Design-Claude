# 11 docx — 워드 문서 만들기·고치기

**쓰는 일:** 기획 ●(보고서·기획서)

부르는 법: "워드로", ".docx" 를 말하면 자동

## 상황별
| 상황 | 이렇게 말하기 |
|---|---|
| 기획서·보고서를 워드 파일로 | "이 계획을 워드 문서로 만들어줘" |
| 받은 워드 파일 내용 읽기·정리 | "data/기획안.docx 내용 정리해줘" |
| 워드 안 이미지 넣기·바꾸기, 찾아 바꾸기 | "이 문서의 표지 이미지 바꿔줘" |
| 수정 내역(변경 추적)·메모 다루기 | "변경 추적으로 고쳐줘" |
| 워드 서식 파일(.dotx) | "이 서식으로 새 문서" |

## 주의
- PDF·엑셀·구글 문서는 대상 아님
- 받은 파일(data/)은 고치지 않고 out/에 새로 만듦(프로젝트 규칙)
