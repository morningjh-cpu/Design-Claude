# 12 Claude Code 기본 명령 — 설치 없이 들어 있는 것

입력창에 `/`로 시작해서 침.

## 대화·작업 관리
| 명령 | 언제 |
|---|---|
| `/clear` | 새 일을 시작할 때 대화를 비우기 (그 전에 HANDOFF.md 갱신) |
| `/compact` | 대화가 길어졌을 때 요약해서 이어가기 |
| `/model` | 쓰는 모델 바꾸기 |
| `/fast` | 빠른 응답 모드 켜고 끄기 |
| `/config` | 설정 화면 |
| `/help` | 도움말 |
| `/artifacts` | 만든 웹 결과물 페이지 목록 |

## 스킬·플러그인
| 명령 | 언제 |
|---|---|
| `/plugin` | 플러그인 설치·삭제·마켓 추가 (예: `/plugin install 이름@마켓`) |
| `/reload-plugins` | 설치 후 다시 불러오기 |

## 개발할 때
| 명령 | 언제 | 예시 |
|---|---|---|
| `/code-review` | 고친 코드의 오류 점검. 강도 low~max | `/code-review medium` |
| `/code-review --fix` | 점검 후 바로 고치기 | `/code-review high --fix` |
| `/simplify` | 고친 코드를 더 간단하게 정리 | `/simplify` |
| `/security-review` | 보안 점검 (개인정보 다루는 화면이면 꼭) | `/security-review` |
| `/run` | 만든 앱을 실제로 띄워 확인 | `/run` |
| `/init` | 새 프로젝트에 CLAUDE.md(작업 규칙 파일) 만들기 | `/init` |

## 반복·예약
| 명령 | 언제 | 예시 |
|---|---|---|
| `/loop` | 같은 일을 일정 간격으로 반복 | `/loop 10m 배포 상태 확인` |
| `/schedule` | 정해진 시각에 클라우드에서 실행 | "매일 아침 9시에 ~ 해줘" |

## 설정
| 명령 | 언제 |
|---|---|
| `/update-config` | "앞으로 ~할 때마다 ~해" 같은 자동 동작, 허용 명령 추가 |
| `/fewer-permission-prompts` | 허락 묻는 창이 너무 자주 뜰 때 |
| `/keybindings-help` | 단축키 바꾸기 |

## 말로 부르는 기본 스킬
- 차트·대시보드: "차트 만들어줘" (dataviz)
- 크롬 자동 조작: "크롬에서 이 사이트 열어 확인해줘" (claude-in-chrome)
- 공유용 웹 페이지 결과물: "페이지로 만들어줘" (artifact)
