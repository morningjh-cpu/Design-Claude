# 09 andrej-karpathy-skills — 코드 짤 때 실수 줄이는 지침

**쓰는 일:** 개발 ●

부르는 법: 코드 작업 시 자동. 직접 `/andrej-karpathy-skills:karpathy-guidelines`

## 4가지 지침
1. 짜기 전에 생각: 가정을 드러내고, 애매하면 묻기
2. 단순하게: 필요한 만큼만
3. 수술하듯: 고칠 곳만 고치고 주변은 건드리지 않기
4. 목표로 확인: "됐다"를 확인할 기준을 먼저 정하기

## 언제 좋은가
- 기존 코드를 고칠 때 엉뚱한 곳까지 바뀌는 걸 막고 싶을 때
- 결과 확인 기준이 필요할 때
