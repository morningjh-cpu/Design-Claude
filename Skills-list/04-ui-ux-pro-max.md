# 04 ui-ux-pro-max — 쓰기 편한 화면 규칙·색·글꼴 추천

**쓰는 일:** 디자인 ●  개발 ●  기획 ●(페이지 구성 패턴)

부르는 법: `/ui-ux-pro-max (요청)` — 안에 검색 자료(스타일 79개, 색 조합 192개, 글꼴 짝 74개, 사용성 규칙 119개)가 있음

## 상황별
| 상황 | 이렇게 말하기 |
|---|---|
| 새 페이지의 색·글꼴·간격 체계를 한 번에 | `/ui-ux-pro-max 금융 구독 서비스 디자인 체계 잡아줘` |
| 사용성 점검(글자 크기, 누르는 크기, 대비) | `/ui-ux-pro-max 이 화면 사용성 점검` |
| 특정 부분만: 폼·오류 표시 | `/ui-ux-pro-max 회원가입 폼 오류 표시 방법` |
| 차트 고르기 | `/ui-ux-pro-max 수익률 비교에 맞는 차트` |
| 사용하는 개발 도구에 맞춘 조언 | `/ui-ux-pro-max Next.js에서 이미지 느릴 때` |
| 결정한 체계를 파일로 저장 | "디자인 체계를 파일로 저장해줘" (design-system 폴더에 MASTER.md 생성) |

## 기억해 둘 기준 (자주 쓰는 것)
- 글자 대비 4.5:1 이상, 누르는 곳 44×44px 이상, 본문 16px·줄간격 1.5

## 이 프로젝트에서 써 본 예
- 1차 C안, 2차 C2, 3차 ③안(글자·버튼 키우고 질문 첫 번째만 펼침)

## 주의
- 추천 색·글꼴이 브랜드와 안 맞을 수 있음(1차 때 어두운 바탕·초록 추천 → 버림). 브랜드가 우선
- 쓰기 편함 위주라 단독으로는 "매력 부족" 평이 나왔음 → 다른 디자인 스킬과 같이
