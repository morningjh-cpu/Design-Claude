# 02 공지사항 3개 화면 개선안 — 계획

대상: 피그마 `15. 공지사항/고객지원` 페이지 > `디자인 변경` 구역 (목록 12533:4710 · 상세 12533:4763 · 관리자 12533:4810)

## 요청 (사용자 말)
- 글쓰기 버튼이 이전 화면들과 차이가 나지 않도록 해줘
- 디자인 스킬을 사용해서 전체 디자인에서 벗어나지 않는 범위에서 개선안을 만들어줘

## 작업 방식
- 원본 3개 화면은 손대지 않는다. 복사본을 옆에 새 구역 `디자인 변경 - 개선안`으로 만들어 고친다.
- 새 색·새 부품을 만들지 않는다. 파일에 이미 있는 버튼·태그·색만 쓴다.

## 찾은 문제와 고칠 내용 (AI 의견)
### 공통 — 글쓰기 버튼
- 이전안: 페이지 제목 오른쪽, 보라색 채움 버튼(btn-fill-primary)
- 지금: 검색 버튼 옆, 흰 테두리 버튼(btn-ot-primary), 높이 36 (검색 버튼은 38) → 높이·모양이 어긋남
- 결정(사용자): **예전 화면처럼** — 페이지 제목+설명을 다시 두고, 그 오른쪽에 보라색 채움 버튼(btn-fill-primary)으로 둔다

### 목록
1. 고정글 카드만 요약문이 있어 카드 높이가 줄마다 다름 → 고정글 카드 줄과 일반 카드 줄 높이를 각각 맞춤
2. 고정글 카드가 보라 배경+보라 테두리 둘 다 써서 무거움 → 배경 또는 테두리 하나만 남기고 '고정' 표시로 구분
3. 분류 탭 간격이 들쭉날쭉 (알림·이벤트 사이가 넓음) → 같은 간격으로 정리
4. 전체 12개인데 페이지 번호가 5까지 있음 → 예시 숫자를 맞춤 (예: 1페이지만, 또는 전체 개수 늘림)

### 상세
5. 삭제 버튼이 진한 채움이라 가장 눈에 띔 → 지우는 버튼은 덜 눈에 띄게(테두리 버튼), 수정과 같은 크기
6. 목록 버튼(왼쪽)과 수정·삭제(오른쪽) 모양이 제각각 → 같은 버튼 묶음 규칙으로 통일

### 관리자(글쓰기)
7. 취소·등록 버튼 크기가 다름 → 같은 크기
8. 유형 선택이 작은 알약 모양이라 다른 입력칸(제목)과 어울리지 않음 → 제목 입력칸과 같은 높이·모양
9. 유형 가이드 표가 늘 펼쳐져 있어 길어짐 → 그대로 두되 글씨 간격만 정돈 (구조 변경은 안 함)
