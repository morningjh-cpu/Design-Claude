# 08 스킬별 사용설명서 — 계획

## 요청 (사용자 말)
개별 스킬에 대해서도 각각의 마크다운 문서를 만들어서 내가 필요할 때 활용할 수 있도록 하고 싶어. 내가하는 일은 디자이너이기는 하지만, 웹사이트 개발을 해야하는터라 기획/개발/디자인 다방면의 작업을 수행해야하는 환경이야. 어떤 상황에서 어떤 명령어를 사용하는게 좋을지 참고할 수 있었으면 좋겠어. 이 마크다운 문서 작성을 어떻게 하면 좋을지 방안을 마련해봐

## 폴더 구성 (Skills-list/)
- 설치한-스킬-목록.md — 지금 있는 전체 목록 (유지, 각 문서로 연결 추가)
- 00-상황별-찾기.md — "지금 이걸 하려는데 뭘 쓰지?" 바로 찾는 표
  - 일의 흐름별: 기획 → 디자인 → 개발 → 점검 → 마무리(글·문서)
  - 상황 예: "페이지가 밋밋해" → impeccable bolder / "피그마를 코드로" → figma design-to-code / "오류가 안 잡혀" → superpowers 오류 원인 찾기
  - 디자인 스킬 4종(impeccable·taste·ui-ux-pro-max·frontend-design)+hallmark 비교표: 언제 어느 것
- 스킬마다 1개 문서 (11개): 01-figma.md … 11-docx.md

## 스킬 문서 한 장의 틀 (모두 같은 순서)
1. 한 줄 요약
2. 쓰는 일: 기획 / 디자인 / 개발 중 어디 (표시)
3. 명령어 표: 명령 · 언제 · 그대로 따라 칠 예시 문장
4. 이 프로젝트에서 써 본 예 (있으면: 3차 ②안, Hallmark 리디자인 등)
5. 주의: 웹 전용인지, 필요한 프로그램, 바깥으로 보내는 정보, 피그마에서 되는 것/안 되는 것
6. 함께 쓰면 좋은 스킬

## 작성 방법
- 기억이 아니라 각 스킬의 설명 파일(SKILL.md·명령 목록)을 직접 읽고 씀 → 명령어 틀림 방지
- 전문용어 없이, 명령어 옆에 한 줄 풀이
- 묶음 스킬(superpowers 14개 등)은 한 문서 안에 하위 명령을 상황별로 묶음

## 유지
- 스킬 설치·삭제 시: 목록 + 스킬 문서 추가/정리 + 상황별 찾기 표 갱신 (CLAUDE.md 규칙 확장)
