# 07 서비스 소개 — Hallmark 리디자인 계획

## 요청 (사용자 말)
홀마크 리디자인, "서비스 소개- 수정버전3"

## 대상
- 피그마 "서비스 소개- 수정버전3" 12568:2015 (3차 ①안을 사용자가 고친 화면, x=6868)
- 원본은 건드리지 않고, 복제본을 오른쪽에 만들어 고침

## Hallmark 방식 적용 (웹 코드용 스킬이라 피그마에 맞게 옮김)
- 깊이: full(기본) — 내용·버튼·문구는 그대로, 배치와 체계(크기·간격·색 쓰임)만 바꿈
- 지키는 것: 모든 문구, 버튼 4개(상단 "플랜 구독" 포함), 플랜 4종 표, 탭 7개, 질문 4개, 상단바·좌우 메뉴·푸터, 보라 브랜드색, Wanted Sans
- 새로 넣지 않음: 버튼·문구·숫자·가짜 화면
- 뽑은 구성(draw 5a1e3c): 첫 화면이 화면 한 장을 다 채움(Settled: 글 6칸·그림 6칸), 첫 화면 아래 바탕을 확 바꿔 구분
  - 버림: "코드 예시로 마무리"(이 서비스에 없음) → 마지막은 기존 하단 띠 유지

## 점검 결과 (Hallmark 기준, 캡처로 판정)
- [필수] 하단 띠의 보라 빛 번짐 그라데이션 → 금지 항목. 단색으로
- [필수] 질문 2~4번: "+"(닫힘) 표시인데 답이 펼쳐져 있음 → 표시와 상태 불일치
- [필수] "광범위하고…" 구역만 왼쪽 시작선이 13px 안쪽으로 어긋남
- [권장] 구역 제목이 작음(1920 화면에서 36px 수준) → 48px 안팎으로
- [권장] 버튼 높이 40px 미만 → 44~52px
- [권장] 구역 사이 간격이 모두 비슷함 → 120px 이상, 구역마다 다르게
- [권장] 첫 화면이 화면 한 장을 못 채우고 아래가 비어 보임 → 첫 화면을 화면 높이로, 그림 칸을 더 크게
- [권장] 빈 그림 칸 2곳 → 그대로 두고, 넣을 자료(실제 서비스 화면 캡처)를 요청
- 유지: 플랜 표의 PLUS 강조, 질문 2단 배치는 잘 됨

## 순서
1. 12568:2015 복제 → 오른쪽에 "서비스 소개- 수정버전3 (Hallmark)"
2. 필수 3개 → 권장 순으로 고침
3. 캡처로 확인 → 고치기 1번 → 결과 기록, HANDOFF 갱신

## 결과 (2026-10-31)
- 질문 처리: 사용자 결정 — 2~4번은 닫아서 질문만 보이게
- 새 화면 12577:3650 "서비스 소개- 수정버전3 (Hallmark)" (x=8988, 원본 오른쪽). 원본 12568:2015는 그대로
- 바꾼 것: 첫 화면을 화면 높이(1026px)로 채우고 글·그림 세로 가운데, 그림 칸 624×640 · 제목 크기 36→48 (FAQ·하단 포함), 첫 화면 제목 1.15배 · 콘텐츠 구역 시작선 맞춤, 탭 높이 36→44, 그림 칸 높이 520 · 질문 첫 번째만 펼침 · 구역 간격 120~180으로 구역마다 다르게 · 하단 띠 그라데이션 → 짙은 보라 단색, 높이 400
- 정정: 계획 때 "버튼 높이 40px 미만"이라 했으나 실제 버튼은 46px로 기준 충족. 작았던 건 탭(36px)이라 탭만 키움
- 남은 것: 빈 그림 칸 2곳 — 실제 와이즈리포트 화면 캡처가 들어가면 가장 좋아짐
