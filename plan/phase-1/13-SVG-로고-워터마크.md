# 13. 심볼 로고 SVG 숨은 워터마크 (2026-11-05)

## 사용자 요청
- 회사에서 제공하는 심볼 로고 서비스용 SVG(구글링·해당 회사에서 찾아 제작)에 회사 워터마크를 남기고 싶다.
- 워터마크는 화면에 보이지 않고 파일에만 있게.
- ①(파일 안 메모) + ②(좌표 숫자에 숨긴 표시) 도구를 만들어 두 파일에 적용.

## 한 일
- 도구: `scripts/svg_watermark.py` (embed 넣기 / check 확인)
- 원본 `data/A0013Y0.svg`, `data/A0077H0.svg` 는 그대로 두고 결과는 `out/watermark/` 에.
- 문구: `FnGuide|<파일 이름>|<원본 파일이 PC에 생긴 날>` 자동 (사용자 결정 2026-11-05, 처음엔 오늘 날짜를 직접 넣었음). 원하면 문구를 직접 줄 수도 있음
- 확인: 두 파일 모두 ①② 읽힘. 메모를 지워도 ②는 남음(A0013Y0 32번 반복, A0077H0 은 좌표가 84개뿐이라 1번).
- 모양 변화 최대 0.00009 픽셀. 비교 화면 `out/watermark/<코드>-전후비교.html` (옛 비교.html 은 _trash 로).

## 알아 둘 것
- 숫자를 반올림하는 압축 도구·피그마 다시 내보내기를 거치면 ②도 사라질 수 있음.
- 개인정보(담당자 이름·이메일)는 넣지 않음. 로고 권리는 원래 회사에 있음 — 워터마크는 파일 제작 출처 표시용.
- 생긴 날은 파일을 복사·다시 받으면 그날로 바뀜 → 원본을 처음 받은 PC에서 넣어야 정확.

## 추가 (2026-11-05): ③ 다른 워터마크 점검
- check·embed 둘 다 자동으로 함. 찾는 것: 주석·metadata·title·desc·글자·그림·숨긴 요소·data- 칸·영문 아닌 글자·유난히 긴 숫자(유효숫자 7자리 이상)
- embed 는 의심되는 게 있으면 멈춤 → 확인 후 `--force` 로 넣기. 편집 프로그램·피그마 흔적은 "참고"로만 보여 주고 멈추지 않음
- 시험: 가짜 표시 9종 넣은 파일 → 모두 잡고 멈춤. 원본 두 파일 → 없음(A0013Y0 은 피그마 흔적 참고 1개)

## 추가 (2026-11-05): ④ 지우기 + 전후 비교
- 사용자 결정: "안전한 것만 제거". 남의 저작권 표시(권리관리정보)를 지우면 저작권법 제104조의3 위반이 될 수 있어서.
- `clean`: 우리 FnGuide 표시(①②)와 편집 프로그램 흔적(Illustrator 등 주석, inkscape·sodipodi 요소·속성)만 지움. 남의 표시로 보일 수 있는 건 "그대로 둠"으로 알려 줌. 끝나면 `<결과>-전후비교.html` 열림
- `preview <전> <후>`: 아무 두 파일 비교. 3배 크기로 그려 한 점씩 비교, 바뀐 곳 빨강
- 시험: 워터마크 넣은 두 파일 → clean → 원본과 글자 하나까지 같음. 섞인 시험 파일 → 편집 흔적만 지우고 ©·소유자 메모는 남김. 같은 파일끼리 0점 차이, 색 바꾼 파일은 "달라졌어요"
- 알게 된 것: 워터마크(②)를 넣으면 A0013Y0 은 3배 크기 81만 점 중 452점(0.06%)이 가장자리에서 최대 23/255 차이, A0077H0 은 59점·최대 9. 그리는 프로그램이 좌표를 반올림하는 경계에 걸려서 생김. 눈으로는 구분 안 됨. 판정 기준: 64/255 넘는 점이 없고 0.5% 미만이면 "미세 차이"
