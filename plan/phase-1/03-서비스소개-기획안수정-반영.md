# 03 서비스 소개 — 기획안 수정 반영

## 요청 (사용자 말)
17. 서비스 소개 페이지에, 서비스소개-기획안 수정에 맞게 서비스소개-디자인 을 변경해줘. 새로운 화면으로 진행.

## 비교 (기획안 수정 12541:17054 ↔ 디자인 7698:97834)
- 같음: 히어로(문구·플랜 살펴보기 버튼), 플랜 4종 표, 콘텐츠 탭, 이용후기(기획안에서 회색 처리 = 디자인에서도 숨김), 자주 묻는 질문, 하단 시작 영역, 플로팅 버튼
- 다름 1: 플랜 표 아래 "플랜 살펴보기" 버튼(라벨 1)이 디자인에 없음
- 다름 2: 리포트 원문 PLUS·MAX — 기획 "일 100건" / 디자인 "월 100건"

## 결과 (2026-10-31)
- 새 화면: `서비스 소개-디자인 (기획안 수정 반영)` 12542:600 (원본 오른쪽)
- 반영: 플랜 표 아래 플랜 살펴보기 버튼 추가(히어로 버튼과 같은 부품), 구역 높이 자동 맞춤
