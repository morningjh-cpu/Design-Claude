# 05 서비스 소개 — 개선안 2차 계획

## 요청 (사용자 말)
A안은 뭐가 바뀐 건지 티가 안나고, B안은 너무 과도하고, C안도 그렇게 매력적이지는 않아.
다시 한번 각 스킬별로 추가 디자인 해봐. 그리고 마지막으로 D안으로 세 스킬을 함께써서 디자인해

## 1차 평가 → 2차 목표
- A(다듬기): 변화가 안 보임 → 구성은 유지하되 "한눈에 달라 보이게"
- B(글자로 말하기): 과함 → 개성은 남기고 강도를 낮춤
- C(쓰기 편하게): 매력 부족 → 편한 구조 + 보기 좋은 화면

## 2차 방향
- A2 impeccable `bolder`(밋밋한 화면 키우기): 첫 화면 연보라 바탕+큰 화면 조각, PLUS 카드 보라로 채움, 제목 크기 키움, 콘텐츠 구역에 실제 미리보기 화면
- B2 taste `one-motif`(모양 하나로 통일): 흰 바탕 유지, "리포트 한 장(모서리 접힌 종이)" 모양 하나를 첫 화면 큰 그림·이미지 틀·배지에 반복. 글자 크기는 1차 B의 60% 수준
- C2 ui-ux-pro-max 바둑판 배치(bento): 콘텐츠 7종을 크기 다른 칸에 미리보기와 함께, 플랜은 카드+선택 버튼, 비교표는 아래에 접어 둠
- D 세 스킬 합침: taste로 "리포트 한 장" 아이디어·글자 크기 대비, ui-ux-pro-max로 비교표·질문 펼침·버튼 구조, impeccable로 마무리 점검(여백·정렬·대비)
