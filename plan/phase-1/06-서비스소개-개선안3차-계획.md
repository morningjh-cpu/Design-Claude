# 06 서비스 소개 — 개선안 3차 계획

## 요청 (사용자 말)
여전히, 좋아보이지 않아. "서비스 소개-디자인 (기획안 수정 반영)" 을 기준으로 다시 한번 디자인 스킬을 사용해줘. 플랜별로 선택하기 버튼이 없는데도 버튼을 만들지 않도록 해. 세가지 스킬 이외에 디자인 수정이 가능한 스킬이 있어?

## 정한 것 (사용자 답)
- 스킬: impeccable · taste · ui-ux-pro-max · frontend-design 각 1안 + 4개 합친 1안 = 5안
- 범위: 요소·문구는 그대로, 구역 안 배치는 바꿔도 됨
- 1·2차 안은 참고하지 않고 새로

## 규칙 (1·2차 반성)
- 기준 화면 12542:600에 있는 요소만 씀. 새 버튼·새 탭·새 문구·새 기능 금지
- 빈 이미지 칸은 빈 칸으로 둠(내용을 지어 넣지 않음). 모양·비율·배치만 디자인
- 기준 화면을 통째로 복제해서 시작 → 상단바·메뉴·버튼·탭·푸터 등 부품과 Wanted Sans 글자를 최대한 그대로 살림 (1·2차는 Noto Sans KR로 새로 그려 글꼴 느낌이 달라졌음)
- 스킬마다 먼저 기준 화면을 진단하고, 그 진단에서 방향을 정함

## 스킬별 진단 → 방향 (2026-10-31)
- 기준 화면 공통 문제: 첫 화면 반이 그림자 진 빈 상자, 제목 36px로 1920 화면에 작음, 모든 구역이 "가운데 제목+작은 보라 글씨" 같은 반복, 플랜 카드 4개가 똑같은 테두리 상자라 추천 플랜이 약함, 하단 그라데이션 띠
- ① impeccable: 정체성 유지, 위계만 정리 — 제목 키우고 왼쪽 정렬, 빈 상자 그림자 제거, PLUS 강조, 질문 2단, 하단 단색
- ② taste(방향 quiet-instrument "조용한 도구"): 왼쪽 한 줄기 단(가로 22% 지점 시작), 구역 띠 없이 여백으로만 구분, 테두리 대신 바탕 톤 차이, 하단은 띠 없이 문장+버튼만
- ③ ui-ux-pro-max(가격 중심 랜딩 규칙): 글자 16px 이상, 누르는 곳 44px 이상(버튼·탭 키움), 추천 플랜 강조, 질문은 첫 번째만 펼침, 하단 단색
- ④ frontend-design(주제 "아침에 도착하는 리포트"): 대담함은 한 곳만 — 첫 화면 짙은 보라 밤하늘 + 아래서 올라오는 연보라 판, PLUS 칸만 짙은 보라로 같은 색 반복, 나머지는 조용히
- ⑤ 합침: ④의 첫 화면 + ①의 왼쪽 정렬 위계 + ②의 테두리 없는 톤 차이·연한 보조 글씨 + ③의 글자·버튼 크기와 질문 펼침

## 결과 (2026-10-31) — 2차 D안 오른쪽에 나란히, 모두 기준 화면 복제본
- ① 12568:2015 · ② 12569:2342 · ③ 12570:2669 · ④ 12571:2996 · ⑤ 12572:3323
- 새 버튼·새 문구·가짜 예시 없음. 글자는 전부 원래 Wanted Sans (크기만 비율로 키움, 색만 바꿈)
- 이미지 칸 2곳은 빈 칸 그대로 (색·모서리·크기만 바꿈)
- 배운 점: Wanted Sans 글자도 "비율 키우기(rescale)·색 바꾸기·폭 바꾸기"는 됨, "정렬·자동 크기"는 안 됨

## 순서
1. 스킬별 진단 → 방향 한 줄씩 이 파일에 기록
2. 기준 화면 복제 5개를 2차 D안 오른쪽에 나란히 → 스킬별로 고침
3. 화면마다 캡처 확인 → 결과 기록, HANDOFF 갱신
