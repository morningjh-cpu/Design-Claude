# 05. 시작하기 페이지 · 부품 설명 틀 (2026-11-13)

파일 `jey6PXIFB19gl5et1XzIzi`. 사용자 요청: "시작하기 페이지와 부품 설명 틀도 만들어줘"

## 만든 것
- 새 페이지 `📍 시작하기`(16013:6) — `프로젝트 정보` 바로 다음 자리.
- 문서 `시작하기`(16013:7, 960×2131): 1. 파일 구성 / 2. 부품 분류 6묶음 / 3. 부품 찾는 법 / 4. 저장값과 글자 스타일 / 5. 지킬 것(01번 원칙 + name 종류 칸 규칙)
- 문서 `부품 설명 틀`(16013:172, 960×1971): 머리(묶음 · 부품 이름 · 용도 한 줄) / 1. 부품 모습 / 2. 종류 칸 / 3. 상태 / 4. 사용 규칙 / 5. 쓰는 저장값 / 6. 쓰인 화면. 안은 회색 안내 글자만(빈 틀).

## 방식
- KRDS 참고: 시작하기 = "파일 구성 살펴보기 · 토큰 사용하기" 짜임, 부품 페이지 = 머리 + 부품 모습(Component) + 종류 표(Guide) 짜임. 사용 규칙·쓰는 저장값·쓰인 화면 칸은 AI 가 덧붙인 것.
- 색은 모두 기존 저장값 연결(tx-primary · tx-secondary · tx-caption · tx-brand · bg-primary · bg-secondary · bd-default · divider-light · divider-strong). 새 저장값·부품 없음.
- 글꼴 Noto Sans KR(Wanted Sans 못 불러옴). 그림 문자는 이 글꼴에서 빈칸으로 나와 표 안 페이지 이름에서는 뺌.
- 부품 설명 틀은 부품(component)이 아니라 일반 틀 — 복사해서 씀.

## 남은 것
- 틀을 실제 부품에 채우는 일은 아직 안 함(어느 부품부터 할지 사용자 결정).
- 글꼴 Wanted Sans 로 바꾸려면 서체 바꾸기 플러그인.
