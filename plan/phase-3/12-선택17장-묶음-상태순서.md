# 12. 선택 17장 — type 별 묶음 · 상태 순서 (2026-11-17)

파일 `jey6PXIFB19gl5et1XzIzi` · 페이지 `📘 부품 설명` · 구역 `4. 입력 / 선택`(16022:794).
사용자: "선택 17장에도 적용해줘" (11번의 type 별 묶음 + 상태 순서)

## 놓은 방식 (세부는 AI 판단)
- type 칸이 있으면 type 별 묶음(묶음 위에 `type=…` 이름표). 묶음 사이 40.
- 묶음 안: 줄 = state(순서대로), 칸 = 나머지 종류 칸. 버튼처럼 줄·칸 이름표 붙임(Noto Sans KR 12, tx-caption / 묶음 이름표는 13, tx-secondary).
- 상태 순서: default · hover · focused · typing · typed · unchecked · unselected · checked · selected · active · partial · disabled · error. `checked hover` · `selected-hover` · `active-hover` 처럼 뒤에 말이 붙은 것은 원래 상태 바로 뒤. (앞 7개 중 입력폼 순서는 사용자, 선택 쪽 낱말 순서는 AI 가 정함)
- 격자가 틀(720)보다 넓으면 격자 대신 "상태 이름표 + 그 상태의 부품을 줄바꿈으로 나열" — 이 경우 칸 이름표 없음.

## 문서별 결과
| 문서 | 방식 |
|---|---|
| checkbox · radio · switch · segment-base-new | 격자(줄 = state, 칸 = disabled / switch-on / between·font-size) |
| dropdown-list | type 3묶음(default · select-combo · check) + 격자(칸 = icon) |
| dropdown-list-simple · flat-select | 한 칸, state 순서로 세로 |
| box-text-select | type 2묶음 + 상태별 줄바꿈 나열(넓어서) |
| dropdown-ui-list | type 3묶음 + 상태별 줄바꿈 나열(넓어서) |
| input-select | type 2묶음 + 상태별 줄바꿈 나열(넓어서) |
| box-date-select | type 없음, 상태별 줄바꿈 나열(넓어서) |
| segment-filter-fixable · segment-filter-size | state 없음 → number 별 묶음(2~6), 안은 selected 순서로 세로 |
| checkbox-round | state 없음(type 칸이 상태 구실) → 순서만 맞춤: unchecked · unchecked hover · checked · checked hover · disabled |
| date-label · dropdown-list-box · dropdown-ui-list-box | 2~3개뿐이고 state 없음 → 그대로 |

- 3. 상태 표 줄 순서도 같은 순서로 맞춤(state 칸이 있는 11장).

## 고친 것
- 격자 칸 높이가 고정돼 줄이 높게 벌어짐 → 칸 높이를 내용에 맞춤.

## 확인

- 눈으로 본 것: dropdown-list · box-text-select · checkbox · segment-base-new 4장. 나머지 13장은 눈으로 안 봄.

## 안 한 것
