1. 전수 조사(읽기만) — 모든 페이지의 부품마다: 이름·위치·종류 수·실제로 쓰인 횟수(어느 페이지에서)·색을 저장값으로 쓰는지 직접 넣었는지
   → 결과표(HTML)를 out/ 에 만들어 크롬으로 엶. "쓰는 것 / 안 쓰는 것 / 겹치는 것"으로 나눔
2. 사용자 결정 — 표를 보고 남길 것·합칠 것·보관할 것을 정함 (이 단계 전엔 파일을 고치지 않음)
3. 기초 정리 — 저장값 718개 점검(안 쓰는 것·이름 규칙), 글자 크기 단계 스타일 새로 만들기, 간격·모서리 값 정리
   - 주의: Wanted Sans는 작업 도구에서 못 불러옴 → Noto Sans로 만들고 끝나면 서체 바꾸기 플러그인 실행
4. 부품 모으기 — 종류별 페이지로 옮김(버튼 / 입력·선택 / 표 / 태그·뱃지 / 아이콘 / 메뉴·GNB / 모달·안내 / 카드 / 페이지 넘김 등)
   - 같은 파일 안에서 옮기면 화면에 놓인 부품 연결은 그대로 유지됨
   - 겹치는 것은 남길 하나로 바꿔 끼운 뒤 나머지는 보관 페이지로
5. 다듬기 — 상태(기본·마우스 올림·비활성 등)·크기 종류 빠진 것 채우기, 이름 규칙 통일, 부품마다 설명 달기(`/design-system document`)
6. 점검 — `/design-system audit` 로 점수·남은 문제 확인 → 라이브러리 발행은 사용자가 피그마에서 직접
