# 23 통합 조회 HTML 다시 만들기 (2026-11-06)

## 사용자 말
- "\"이걸로 HTML 만들어봐\" 페이지로 HTML을 다시 만들어봐. 방금 전에 만든건 선도 빠져있고, 아이콘도 제멋대로 바꿔서 실제 HTML 비교하는데 어려워. 제대로 다시 만들어봐"

## 방법
- 대상 프레임: `디자인-` 페이지의 `이걸로 HTML 만들어봐`(14294:77567)
- 손으로 다시 그리지 않고, 피그마 레이어를 그대로 옮기는 변환 도구로 뽑음: 자동 배치 → flex, 여백·간격·크기 방식(고정/채우기/내용 맞춤)·선(안쪽 선을 그림자로)·모서리·색·글자 크기/굵기/줄 간격/자간 그대로. 아이콘·로고·종목 마크는 피그마에서 SVG로 직접 내보냄
- 조각 4개(`out/통합조회-v2/parts/`) + 틀(`template.html`) → `py -3 build.py` → `index.html`
- 피그마 위 브라우저 그림(주소창)은 뺌

## 결과
- `out/통합조회-v2/index.html`. 1920 화면 캡처로 피그마와 맞춰 봄 (선·아이콘·색 같음)
- 손본 곳: 크기 없이 나온 아이콘 4종 크기 넣음, '관심 설정' 아이콘 배경색(SVG에 안 담김) 따로 넣음
- 동작: 검색(칩·최대 5개), 기간 버튼·직접입력 달력, 산업/제공사/페이지수 펼침(제공사·페이지수는 걸러짐, 산업은 표에 정보가 없어 이름만), 몇 개씩 보기, 머리칸 정렬, 탭·하위 탭 선택, 쪽 버튼, 제목 누르면 읽음, 본문 제한 안내, 왼쪽 별 즐겨찾기, 오른쪽 종목 선택·하트·종목 검색
- 첫 화면은 피그마 그대로(3번째 줄 마우스 올린 회색). 표에 마우스가 들어오면 실제 마우스를 따라감
- 예시 줄이 15개라 2쪽 이상은 안내만, 기업 외 탭은 표 그대로
