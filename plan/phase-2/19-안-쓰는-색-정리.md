# 19 안 쓰는 색 저장값을 unused 폴더로 — 2026-11-03

## 사용자 말
- "배리어블에 안쓰는 색을 정리해서 배리어블의 unused 폴더로 이동해줘."

## 기준
- 쓰임 = 어느 레이어(부품 속·숨김 포함)나 색·효과 스타일에 연결됨 + 쓰이는 저장값이 가리키는 저장값(이어서 따라감)
- 보관 페이지는 보지 않음 (사용자 규칙). 파운데이션 페이지는 봄 (색 견본이 연결돼 있어서)
- 이미 unused 폴더에 있는 것, 사용자가 "그대로 둬" 한 tx-ddl-add · tx-ddl-add-hover 는 옮기지 않음

## 결과 (모음 wisereport 색 729개)
- 쓰이는 것 536 · 옮긴 것 166 → unused 폴더 안 합계 197
- 옮기는 방법 = 이름 바꾸기만: `base/sub/lime-100` → `base/---- unused/sub/lime-100`, `semantic/text/tx-srch` → `semantic/---- unused/text/tx-srch` (원래 묶음 경로를 폴더 안에 그대로 둬서 되돌리기 쉬움, 겹치는 이름 0)
- 옮긴 것 예: base 42 (iris-5, lime, turquoise, amerald 일부, neutral/black …), semantic 124 (chart/cat-bg-01~11, table/bg-th·bg-cell…, button/…---- 임시 이름들, dropdown-list delete·disabled 계열, border/bd-srch … 등)
- 보관 페이지에서만 쓰이던 색이 있었다면 함께 옮겨졌을 수 있음 (보관은 보지 않았으므로). 이름만 바뀐 것이라 연결은 그대로
- 사용자 "tx-ddl-add와 tx-ddl-add-hover 안쓰면 같이 옮겨" → 쓰는 곳 없음(앞서 전체 확인) → semantic/---- unused/dropdown-list/ 로 옮김. unused 폴더 합계 199
