- 뜻을 맞춘 말
  - **"끊긴 색"** = 색 이름은 보이는데 목록에서 선택 표시가 안 되는 색 (다른 파일 저장값에 걸림). 13번처럼 "직접 넣은 색"과 헷갈리지 않게 이 말을 씀

- 지시 틀: `[어디] 끊긴 색 [찾아줘 | 표시해줘 | 다시 연결해줘]`
  - 어디 = 페이지 이름, 구역 이름(예: 15. 공지사항), 부품 이름(예: notice-card), 또는 "전체"

- 기본 동작 (따로 말 안 하면)
  - 부품 원본부터, 그다음 화면
  - 같은 이름이 없는 것은 연결하지 않고 빨강으로 표시해서 물어봄
  - 연결 뒤 색이 달라지는 곳은 목록으로 알려줌
- 예: "공통 컴포넌트 끊긴 색 다시 연결해줘", "5. 기업분석 끊긴 색 표시해줘"
