# 09 5단계 이어서: 철자 고치기·빠진 상태 그리기 — 2026-11-03

## 사용자 결정
- 이름: 철자만 고치기 (name 칸·selected/active 통일은 개발과 맞춘 것일 수 있어 그대로)
- 빠진 상태: 그리기
- 글자 스타일: 아직 Wanted Sans로 안 바꿈 → 연결은 나중

## 철자 고친 것 (종류 칸 이름 — 화면 연결 유지)
- home-search-bar·service-search-bar: muilti-search → multi-search
- cell-text-link: best-anayst → best-analyst
- title-unit: lunk → link
- count-unit: listng-select → listing-select
- td-first-text: "horizontal -header" → horizontal-header
- btn-fill-secondary: 작은 크기의 임시값 state6/5/4 → default/hover/disabled (색 저장값으로 확인)
- 부품 이름(txet-btn, arrow-folter-down 등)은 앞서 "이름 그대로" 결정에 따라 안 바꿈
- 참고: radio 의 `dafault` 는 다른 파일(라이브러리) 부품에 있던 것 — 이 파일 radio 는 문제없음

## 새로 그린 상태 7개 (기존 상태를 복제하고 그 부품 전용 저장값으로 색만 바꿈)
- linetab: hover(tx-linetab-hovered) 14018:1418 · disabled(tx-linetab-disabled) 14018:1420
- modal-tab 탭 모양: hover(bg/bd/tx-tab-unselected-hover) 숫자 있음 14018:1422·없음 14018:1430 · disabled(bg/bd/tx-tab-disabled) 14018:1426·14018:1432
- pagination-btn: disabled(bg-btn-disabled·tx-btn-disabled) 14018:1434
- 화면 캡처로 확인함

## 전용 저장값이 없어 못 그린 것 (사용자가 색을 정해야 함)
- checkbox·radio 마우스 올림, switch 마우스 올림
- tag-basic 비활성, btn-login·filter-reset 비활성
- modal-tab 밑줄 모양(type=line)의 hover·disabled
- tab-solid: 상태 칸이 없는 낱개 부품
- 쓸 만한 공통 저장값 후보: select/bd-select-hover, border/bd-disabled, text/tx-disabled, icon/ic-disabled (공통용이라 맞는지 사용자 판단 필요)
